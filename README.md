# Latchpoint website

A static site — no build step, no server needed. Three files: `index.html`, `styles.css`, `script.js`.

## Before you launch
- Swap `hello@latchpoint.co.uk` in `index.html` for your real email (or Gmail alias) once you've set one up.
- Swap the Instagram link for your actual handle once the account's live.
- Everything else (copy, pricing, colors) is yours to edit directly in `index.html` / `styles.css` — it's plain text, no tooling required.

## Free hosting — pick one

**Netlify Drop (easiest, no account needed to try)**
1. Go to https://app.netlify.com/drop
2. Drag the whole `latchpoint-site` folder onto the page
3. You get a live URL instantly. Create a free account to keep it permanently and add a custom domain later.

**GitHub Pages (good if you're already using GitHub)**
1. Create a new repository, e.g. `latchpoint-site`
2. Upload these three files to it
3. In the repo's Settings → Pages, set the source to the `main` branch, root folder
4. Your site is live at `https://<your-username>.github.io/latchpoint-site`

**Cloudflare Pages (fast, free, good if you'll want a custom domain later)**
1. Sign up at https://pages.cloudflare.com
2. Create a project, upload this folder (or connect a GitHub repo)
3. Deploy — you get a free `*.pages.dev` URL, with easy custom domain setup once you buy `latchpoint.co.uk` or similar

Any of the three get you a live link to put in your Instagram bio today. A custom domain (e.g. from Namecheap or 123-reg) can be pointed at any of these later for a few pounds a year.
